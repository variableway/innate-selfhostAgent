# 你的第一个可执行教程

欢迎来到 **Innate Playground**。本教程用最简单的方式带你熟悉界面:
编辑代码 → 立即执行 → 看输出。

## 你会学到

- 如何在教程里编辑代码块
- 如何在浏览器里直接执行 Node.js / Bash / PowerShell
- 如何跳到下一个教程

---

## 1. 执行一段 Shell

下面这段代码会打印当前时间和 Node.js 版本。每个教程的代码块都是
**可编辑的** —— 改完按运行,马上看到结果。

### macOS / Linux(以及装了 Git Bash 的 Windows)

```bash {executable}
echo "👋 Hello from Innate Playground"
echo "Node version: $(node -v 2>/dev/null || echo 'not installed')"
echo "Date: $(date)"
```

### Windows PowerShell

```powershell {executable}
Write-Host "👋 Hello from Innate Playground"
Write-Host "Node version: $((node -v) 2>$null -replace [Environment]::NewLine,'')"
Write-Host "Date: $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')"
```

> 桌面应用启动时,后端已经预启动了一个真实的 PTY 终端(Windows 上
> 优先用 Git Bash / WSL bash,macOS 用 zsh,Linux 用 sh)。点"运行"会把
> 命令直接写入那个 shell,**不需要任何权限授权弹窗**——它就是你电脑上的
> 真实 shell,所以请只运行你信任的教程命令。

> **不知道自己在哪个 shell?** 看桌面应用底部终端面板的提示符:
> `bash-5.x$` 是 bash / Git Bash,`PS C:\>` 是 PowerShell,`C:\>` 是 cmd。

## 2. 执行一段 Node.js

试试把变量名 `greeting` 改一改,再运行一次:

```javascript {executable}
const greeting = "Hello, world!";
const lang = "Node.js";
const version = process.version;
console.log(`${greeting} (running on ${lang} ${version})`);

const items = ["🍎 apple", "🍌 banana", "🍇 grape"];
items.forEach((it, i) => console.log(`${i + 1}. ${it}`));
```

## 3. 试试出错会发生什么

把下面代码里的 `JSON.parse` 改成解析一个非法字符串,运行后会看到
**红字错误信息**。把它改回去,再运行一次 —— 错误消失。

```javascript {executable}
try {
  const data = JSON.parse('{"ok": true}');
  console.log("Parsed OK:", data);
} catch (err) {
  console.error("Parse failed:", err.message);
}
```
